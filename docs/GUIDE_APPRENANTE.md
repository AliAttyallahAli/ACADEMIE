# 🎓 Guide apprenante ALKHER ACADEMY

Bienvenue sur ALKHER ACADEMY ! Ce guide vous accompagne pas à pas.

## 1. Créer un compte

1. Aller sur `https://alkher-academy.com`
2. Cliquer **S'inscrire**
3. Remplir :
   - Nom complet
   - Date de naissance
   - Email
   - Mot de passe (min. 8 caractères, 1 majuscule, 1 minuscule, 1 chiffre)
4. Créer mon compte → connexion automatique

## 2. Installer l'application (mobile)

### Android (Chrome)
1. Ouvrir le site
2. Bannière **"Installer ALKHER ACADEMY"** → cliquer **Installer**
3. L'icône apparaît sur l'écran d'accueil

### iPhone (Safari)
1. Ouvrir le site
2. Bouton **Partager** → **Sur l'écran d'accueil**
3. Confirmer

L'app fonctionne ensuite comme une application native.

## 3. S'inscrire à un module

1. Menu **Modules** (ou icône 📚 en bas sur mobile)
2. Onglet **Catalogue**
3. Parcourir les modules disponibles
4. Cliquer **S'inscrire** sur un module
5. Confirmer le paiement via **AlkherPay**
6. Une fois validé, le module apparaît dans **Mes modules**

## 4. Suivre les cours

Après inscription :

1. Menu **Dashboard** → voir la **prochaine séance**
2. Cliquer **Commencer**
3. Lire/regarder le contenu de la séance
4. **À la fin** : passer le **quiz d'évaluation**

### Comment fonctionne le déblocage ?

- 🔓 **Séance 1** : disponible immédiatement
- 🔒 **Séance 2** : **verrouillée jusqu'à** :
  - La date programmée **ET**
  - Réussite du quiz séance 1 (**≥ 60%**)
- Et ainsi de suite jusqu'à la dernière séance

📅 **Les séances s'ouvrent progressivement** selon votre calendrier (ex : 2x/semaine).

## 5. Réussir les quiz

1. Lire les questions (une seule ou plusieurs réponses possibles)
2. Cocher les bonnes réponses
3. Soumettre
4. **Résultat immédiat** :
   - ✅ **Réussi** (≥ 60%) : séance suivante débloquée
   - ❌ **Échoué** : possibilité de retenter (max 3 fois)

### Conseil
- 📖 Relisez le cours avant de répondre
- ⏰ Ne perdez pas de tentatives sur des questions au hasard

## 6. Recevoir son certificat

Quand **toutes les séances de tous vos modules** sont validées :

1. Notification **🏆 Formation terminée**
2. Aller sur **Dashboard** → bouton **Page d'orientation**
3. Cliquer **Télécharger PDF** → certificat avec **QR code**

### Le QR code
- Chaque certificat a un **QR unique**
- **Recruteurs** peuvent scanner → page de vérification en ligne
- **Signature HMAC** garantit l'authenticité

### Comment utiliser le certificat
- 📄 Ajouter à votre CV / LinkedIn
- 🤝 Présenter le QR à un recruteur
- 📝 Mentionner dans vos candidatures

## 7. Postuler à une bourse

1. Menu **Bourses** (icône 💼)
2. Filtrer par type (formation / recherche / stage)
3. Cliquer sur une bourse → **Postuler**
4. Remplir :
   - **Lettre de motivation** (50-2000 caractères)
   - **CV** (PDF, DOC, DOCX)
5. Envoyer → **candidature en attente**

### Suivi
1. Menu **Mes candidatures**
2. Voir le statut :
   - ⏳ **En cours d'examen**
   - ✅ **Acceptée** (notification 🎉)
   - ❌ **Refusée** (avec motif)

## 8. Notifications

- 🔔 **Cloche** dans le header → nombre de non-lues
- **Types** : nouvelle séance, quiz réussi/échoué, module terminé, certificat, réponse forum/support, bourse
- **Clic** → redirige vers la cible + marquée lue
- **Temps réel** : mises à jour instantanées

## 9. Profil

### Modifier vos informations
1. Menu **Profil**
2. Cliquer **📷** sur votre avatar → uploader une photo
3. Modifier nom, téléphone, pays, bio
4. Enregistrer

### Changer de mot de passe
1. Section **Sécurité**
2. Mot de passe actuel + nouveau + confirmer
3. Enregistrer

## 10. Forum et Support

### Forum
1. Menu **Forum**
2. Choisir un module (dans lequel vous êtes inscrite)
3. **Créer un sujet** ou **répondre** à d'autres

### Support
1. Menu **Support**
2. **Créer un ticket** (sujet + message)
3. Suivre la réponse de l'équipe
4. Statut : Ouvert → Répondu → Clôturé

## ❓ FAQ

**Q : Je n'accède pas à ma séance.**
R : Vérifiez que (1) votre inscription est payée, (2) la séance précédente est validée, (3) la date est atteinte.

**Q : J'ai échoué au quiz 3 fois.**
R : Contactez le support via `/support`.

**Q : Mon certificat ne s'est pas généré.**
R : Vérifiez que **toutes** les séances de **tous** vos modules sont validées.

**Q : Puis-je suivre plusieurs modules ?**
R : Oui, inscrivez-vous à autant de modules que souhaité. Le déblocage est indépendant par module.

**Q : Le site ne s'installe pas sur mon téléphone.**
R : Sur iPhone, utilisez Safari (pas Chrome) → Partager → Sur l'écran d'accueil.

**Q : J'ai oublié mon mot de passe.**
R : Contactez le support pour réinitialisation.
